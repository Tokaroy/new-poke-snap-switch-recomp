# Save states across the end-of-course Evaluation (docs/save-states.md): (1) the state from just before photo select is loaded back after the Evaluation
# (the game must be back in the ride, then play on to a second Evaluation of the same photos); (2) a state saved ON the Evaluation score screen is loaded
# back at the Evaluation end. Threads the course end creates are parked for good by the load; memory regions the game frees stay reserved while a state exists.
# Run: powershell -File host\run_boot.ps1 -Route savestate_eval_across -Timeout 600 -ShotAt 280 -ShotEvery 6 -ShotMax 8
# Pass: boot_stderr.log has two "state load ... ok", "wait 'ui=evaluation:End' met" three times, and "end of route reached" (exit code 0).
